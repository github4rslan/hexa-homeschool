## Bugs (Critical → Low)

- [x] **B1 · Low (a11y) · Question figure announces generic filler alt to screen-reader / auto-narration children** — `src/app/api/question-visual/route.ts:105,184`
  - Repro / evidence: In the Maths lesson, the practice + mastery questions
    "Simplify 4x + 2x", "Write 3 × n as simply as possible", "Expand 2(x + 5)"
    each render `<figure><img alt="Helpful visual for this mathematics question."></figure>`.
    The alt is a fixed template string for every AI/placeholder figure regardless
    of what the image shows, so a child using the screen reader or the built-in
    auto-narration hears meaningless filler on every non-derivable prompt. (When
    `deriveMathVisual` DOES produce a real spec — fractions, number lines,
    arrays — the alt is honest; this only bites the AI-fallback path, which is
    exactly the algebra/text questions.)
  - Root cause: the AI question-visual route hard-codes
    `alt: \`Helpful visual for this ${question.subject} question.\``; there is no
    per-image description and no "decorative" path.
  - Fix (smallest correct): when the figure is the generic AI/placeholder
    fallback (no derived `MathVisualSpec`), render it decoratively — `alt=""` +
    `role="presentation"` in `src/components/child/math-visual.tsx` — so assistive
    tech and narration skip it, instead of reading a non-description. (Superseded
    for algebra specifically by F1, which gives these prompts a real described
    visual.)
  - Risk: none functional — a11y-only. Keep honest alt for the derived specs.
