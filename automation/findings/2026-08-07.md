## Bugs (Critical → Low)

- [x] **B1 · Low · "Avg lesson time" target band is mis-calibrated for Edway's short quests** — `src/lib/engine/dashboard-stats.ts:9-24`
  - Repro / evidence: parent dashboard "This week" → **Avg lesson time** card reads
    **"2m · below the 45–60 min target"** (live this run). The band is a hardcoded
    per-lesson 45–60 minutes (`LESSON_TIME_TARGET_MIN_SEC = 45*60`). But an Edway lesson is a
    focused interactive **quest** (Explainer → a few practice Qs → 3-question mastery) that
    takes ~2–15 min *by design* — so `avgLessonTimeHint()` will return **"below the 45–60 min
    target" for essentially every real family, forever.**
  - Root cause: the 2026-07-25 fix correctly made the caption *dynamic* (below/within/above),
    but the underlying target band was never re-calibrated to the product's actual
    short-quest model — so the honest caption now honestly reports a target that doesn't fit.
  - Fix: recalibrate the band to the interactive-quest reality (e.g. a healthy ~8–20 min per
    quest), OR reframe the card as *daily total study time* rather than *per-lesson* (sum the
    day's quests) and set the band accordingly. Update the unit test in
    `tests/` that pins the current thresholds. Small, but needs the owner's intended band —
    default to ~8–20 min per quest if unspecified.
  - Risk: none technical; it's a product-calibration call. Keep the caption honest (the
    below/within/above logic is already right — only the constants move).
