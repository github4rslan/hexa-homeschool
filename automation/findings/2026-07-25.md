- [ ] **B1 · Low · Dashboard "Avg lesson time" caption is always "within 45–60 min target", even when it isn't** — `src/app/(dashboard)/dashboard/page.tsx:393`
  - Repro / evidence: parent dashboard "This week" card shows **"3m · within 45–60 min target"** — 3 minutes is plainly not within a 45–60 minute band, so the reassurance reads as broken/contradictory.
  - Root cause: `hint={avgSec ? "within 45–60 min target" : "no lessons yet"}` — the "within target" string is hardcoded for any non-zero average.
  - Fix: make it a neutral target label ("target: 45–60 min") OR compute the real relation (`avgSec within [2700,3600] ? "within 45–60 min target" : "below the 45–60 min target"`). Prefer the honest computed version.
  - Risk: pure copy/logic on one StatCard; no data change.

  - Root cause: two independent greeting surfaces (DashboardTopbar + TodayBriefingHeader) both interpolate the first name.
  - Fix: drop the name from one (e.g. topbar keeps time-of-day greeting, briefing header leads with the child summary), or merge into a single greeting line.
  - Risk: trivial; both are presentational.

- [ ] **B3 · Low · `/schedule` shows a raw ISO week key to the parent** — schedule page header
